# Фронтенд CRM — React/TypeScript

Экспорт для разработчика от 19.10.2026. Пакет выделен из подготовленной локальной версии `crm-description-release`. Эта версия включает доработки, публикация которых не подтверждена; она может отличаться от работающего сайта.

## Состав

- `app/` — экраны, React-компоненты, CSS, маршруты и общий layout. Обработчики `app/api/` исключены.
- `components/ui/` — общие UI-компоненты.
- `hooks/` — React-хуки.
- `lib/` — только модули, необходимые импортам интерфейса: поля и проверки, фильтры, слои карты, ТЗ, рабочий план и другие общие функции.
- `public/` — статические ресурсы, Leaflet и PDF worker; `vendor/` — стили и лицензия.
- `package.json`, `package-lock.json`, конфигурация и скрипты исходной системы сборки Vinext/Vite.

Сохранена структура React-приложения. Единого автономного HTML-файла у этой версии нет: страницы рендерятся приложением и обращаются к серверу. Для открытия исходников использовать редактор кода; двойной щелчок по `.tsx` не запускает портал.

## Зависимости и подключение

Основные технологии: React 19.2.6, TypeScript 5.9.3, Next.js API 16.3.4, Vinext 1.0.0-beta.5, Vite 8.0.13, Tailwind CSS 4.2.1, Radix/shadcn, Leaflet. Версии зафиксированы в lockfile. Требуется Node.js >=22.13.0.

Для установки зависимостей из новой отдельной папки:

```sh
npm run install:ci
```

Команды `npm run dev -- --port 5175 --hostname 127.0.0.1` и `npm run build` сохранены из исходного приложения. Для полноценной работы нужно подключить совместимый backend. Без него экраны, которые загружают данные, покажут ошибку API. Backend, база и API-заглушки в этот пакет не входят.

Все обращения сделаны к относительным адресам. Backend должен быть доступен на том же origin либо через настроенный серверный proxy. Основные маршруты API:

| API | Для чего нужен |
| --- | --- |
| `/api/crm` | Контакты, ТЗ, предложения, сделки, задачи и история |
| `/api/objects` | Загрузка, добавление и редактирование объектов |
| `/api/positions` | Координаты и подтверждение точек |
| `/api/object-communications` | Коммуникации по объектам |
| `/api/brief-sources`, `/api/brief-batch` | Источники ТЗ и пакетное создание |
| `/api/collections`, `/api/collections/export` | Подборки и экспорт |
| `/api/object-intake`, `/api/object-intake/source` | Распознавание новых объектов и документы |
| `/api/visits` | Регистрация и просмотр посещений |

Точные тела запросов, методы и обработка ответов находятся в соответствующих React-компонентах. Полная серверная реализация передана отдельно в архиве `CRM-source-for-developer-2026-10-19.zip`.

Маршруты и layout используют `app/chatgpt-auth.ts`. На Sites личность посетителя подтверждает платформа. В отдельном production-развёртывании необходимо подключить проверяемые серверные сессии и ограничения доступа; принимать присланные браузером заголовки личности как доказательство входа нельзя. Локальная имитация входа предусмотрена только для loopback-предпросмотра. ID работающего Site в пакете отсутствует.

## Данные и отличия от полного пакета

Рабочие объекты, контакты, документы, базы и секреты не включены. Три JSON-массива реестров оставлены пустыми, два JSON-индекса — пустыми объектами. Часть интерфейса импортирует их как исходный набор данных.

Исходные компоненты и стили скопированы без изменений из ранее подготовленного пакета. В нём email администратора журнала уже заменён на `owner@example.test`. В этом фронтенд-экспорте изменено имя npm-пакета и удалена команда `db:generate`, поскольку схема базы исключена. `.openai/hosting.json` содержит только декларации bindings, без ID проекта. В шапке сохранена исходная ссылка на рабочую карту; при самостоятельной установке её можно заменить в `app/layout.tsx`.

Не включены `app/api/`, `db/`, SQL-миграции, отдельные серверные хранилища, серверный вызов OpenAI, тестовые данные, `node_modules`, Git и локальное runtime-состояние.

## Проверка экспорта

- Перед копированием проверены SHA-256 исходного очищенного пакета.
- Разрешены 199 локальных ссылок импорта в компонентах и общих модулях; отсутствующих файлов не найдено.
- Проверены пустые JSON-реестры, отсутствие runtime-каталогов, файлов базы, секретов и обработчиков API.
- Для всех файлов подготовлены SHA-256 в `FRONTEND-MANIFEST.json`; целостность ZIP проверена.
- Повторная сборка и браузерная проверка выделенного фронтенда не выполнялись. Прохождение тестов полного пакета не означает проверку автономной работы этой клиентской части.

Рабочая CRM, карта и исходные данные при экспорте не изменялись.
